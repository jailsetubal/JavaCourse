# Orientação a objetos

## Atributos:
### São todas as características que o objeto possui
### Ex: Objeto pessoa possui (Idade, Altura, peso, etc...)

## Métodos:
### Métodos são as ações que o objeto é capaz de realizar
### EX: Objeto pessoa (Correr, pegar, empilhar, caminhar, etc...)

## Herança:
### Permite a reutilização da estrutura e do comportamento de uma classe

## Polimorfismo:
### É atribuído através de um comportamento genérico
### EX: Mamíferos e répteis *emitem som*, mesmo que diferentes sons, o *comportamento* é o mesmo.
